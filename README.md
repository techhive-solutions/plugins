# TechHive plugins

Claude Code plugin marketplace for TechHive Solutions and Zuhal Systems Inc.

## Install

In Claude Code:

```
/plugin marketplace add techhive-solutions/plugins
/plugin install <plugin-name>@techhive-plugins
```

Or install a plugin in one step (Claude Code 2.1.275 or later):

```
/plugin install google-workspace-steward --marketplace techhive-solutions/plugins
```

## Plugins

| Plugin | Description |
|---|---|
| `google-workspace-steward` | Find what is using Google Workspace pooled storage: the largest Drive files, top users and storage growth. For super admins; read-only, metadata only. |
